# TipCalc — калькулятор чаевых

**Лабораторная работа №3**

Дисциплина: «Прикладные задачи мобильных технологий».

## Цель работы

Разработка Android-приложения для расчёта чаевых, скидки и итоговой стоимости заказа с использованием Jetpack Compose.

## Реализованные функции

- Ввод суммы заказа и количества блюд.
- Выбор чаевых от 0 до 25% с шагом 5%.
- Отображение суммы чаевых через Snackbar.
- Автоматическое определение скидки по количеству блюд.
- Программное переключение RadioButton.
- Отображение суммы скидки.
- Расчёт итоговой суммы после нажатия кнопки «Итого».
- Автоматическое обновление интерфейса при изменении данных.

## Правила скидок

| Количество блюд | Скидка |
|---|---|
| 1–2 | 3% |
| 3–5 | 5% |
| 6–10 | 7% |
| Более 10 | 10% |

## Формула итоговой суммы

Итого = Сумма заказа − Скидка + Чаевые.

## Используемые технологии

- Kotlin
- Jetpack Compose
- Material Design 3
- Compose State
- Kotlin Coroutines
- Git и GitHub

## Запуск

Открыть проект в Android Studio, выполнить Gradle Sync и запустить конфигурацию `app` на Android-устройстве или эмуляторе.

## Результат

Реализован калькулятор чаевых с автоматическим определением скидки и вычислением итоговой суммы заказа.
